**Common Vulnerabilities and Exposures** (CVEs) are public security issues with unique IDs.

# Creating a CVE
1. Check if issue is vulnerability
2. Reach out to affected product
3. Check Vendor CNA/Third party CNA
4. Fill CVE form
5. Receive CVE ID
6. Public disclosure
